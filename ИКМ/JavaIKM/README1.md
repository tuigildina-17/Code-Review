Цель: провести код‑ревью существующей проектной работы и улучшить её качество, включая оформление кода, корректность данных и визуализацию архитектуры.
--------------------------------------------------------------------------------------------
Выполненные задачи:
- Проведено код‑ревью существующего приложения: Проверена структура проекта, логика слоёв, корректность взаимодействия между компонентами.
- Приведён код к единому стилю: Заменены табуляции на пробелы, сокращены длинные строки, улучшена читаемость.
- Добавлена валидация данных: Реализована проверка диапазона года рождения для повышения надёжности ввода.
- Создана диаграмма классов: Построена диаграмма, отражающая архитектуру и связи между основными сущностями.
--------------------------------------------------------------------------------------------
Краткая структура приложения:
- Controller — обработка запросов пользователя
- Service — бизнес‑логика и преобразование данных
- Repository — работа с базой данных
- Entity — модели данных
- DTO — передача данных между слоями
- Thymeleaf — отображение данных в HTML‑шаблонах
