ОТЧЁТ ПО ЛАБОРАТОРНОЙ
- Исправленные ошибки:
1. Устранение табуляции
- Табуляции в коде были заменены на стандартные пробелы, что привело стиль форматирования к единому виду.
2. Добавление Javadoc‑комментариев
- Для всех методов и ключевых классов были добавлены корректные Javadoc‑комментарии, описывающие назначение, параметры и возвращаемые значения.
3. Удаление ненужных комментариев
- Устаревшие, дублирующие и неинформативные комментарии были удалены, что улучшило читаемость кода.
4. Добавление обработки исключений и корректной проверки ввода
- Была исправлена основная проблема программы — падение при некорректном вводе.
- Выполнено:
- - Методы numberNum() и numberNumMiu() переписаны: теперь они используют nextLine() + Integer.parseInt() внутри try/catch, что полностью исключает InputMismatchException.
- - Добавлен универсальный метод safeInt() для безопасного чтения целых чисел без диапазона (используется в меню).
- - Удалено использование nextInt() во всех частях программы.
5. Изменение названия метода
- Была исправлена ошибка в названии метода (meni -> menu).
